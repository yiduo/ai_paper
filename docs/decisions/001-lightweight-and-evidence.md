# ADR 001：轻量规范图谱与保守证据

日期：2026-10-20。状态：采用。

初期用 JSONL 规范记录、标准库校验和按需图查询，不引入图数据库。当前 372 个成果族、719 条手稿及少量研究节点不足以证明服务型基础设施必要。GraphML、压缩 JSON 和单页离线检视器从同一加载器产生；不维护平行事实库。

上游维持现有只读克隆并在本项目 Git 中忽略，用远程 URL、commit、逐文件散列和获取脚本固定。全量文件清单 gzip 约 7 MB；只在有检验需要时提取正文。实验原始输出、数值汇总与源代码输入快照均压缩，临时复现目录自动删除。

没有真实数学审核和第二供应商，先继续 OpenAI 当前会话可独立完成的工作。不会把同模型不同角色算作独立来源；未审谱系保持未知。用户明确授权后续追加资源，执行不得反复为此停顿。

范围说明发现：显式 formalization.yaml 来源链接和 Lean scope 文档链接数量不同。此前仅靠 YAML 在缺省分支标 C 的加工口径不成立，处理版本 2 改为逐条审查前未知，保留版本 1 压缩归档。此项不能靠选择较大的数字解决；必须逐命题核对主结果/支持结果范围。
