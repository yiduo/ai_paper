# 有限玻色子回归的复现与边界

`EXP-273-001` 是已实际运行的自用软件回归原型。目标是检验F273熵下界能否比合格旧熵界多发现固定输出故障；结果为零额外检出，保留为应用“观察”。它不是外部量子库、硬件、通信容量或无限维定理的验证。

标准库核心检查仍不需要NumPy。这个单独的可选实验严格要求Python3.12.14与NumPy2.3.5；检查在运行前执行。当前电脑复用了现有环境，没有安装依赖。外部使用者如需自行配置，可在该Python的隔离环境安装本项目的`bosonic` extra，或安装固定NumPy版本；不要将环境或缓存提交仓库。

规格在本地提交`3a05131`冻结，任何实现／场景输出之前确定；计算代码在`d201e60`保存后首次运行。9组公开可审查的合成有限支持输入，各取4个固定旋转，共36场景；7类预先固定故障共252输出。数据、故障与阈值没有按结果调整。

每端口最多2模式，总光子支持上限2；联合总数不超过4。完整联合基的维数最多70，输出基最多15。被动混合保持总数，故完整有限支持对这批输入严格封闭；没有把无限热态随意截断、归一化后称无误差。输入用精确有理数混合与生成算子基表示，含内部纠缠、非高斯混合和不等熵；两个端口则始终独立。独立的端口相关Bell负对照根据实际部分迹与张量积不等被拒绝，未代入任何熵不等式。

候选模拟器用完整数基上的Hermitian生成元作特征分解并取指数。参考核独立展开产生算子的有理数多项式，逐纯态检查范数与总能量，精确部分迹得到密度矩阵。两个核不共享通道变换公式；它们仍由同一会话编写，不冒充独立供应商或真人审核。四项标准库物理／边界测试覆盖单光子二项损耗、双光子干涉、阶乘归一化、支持资格、内部纠缠与相关端口排除，以及逆函数和端点。

熵计算不把浮点特征值直接当证书。对准确表示的实对称IEEE矩阵A，取数值特征向量V与对角Λ，随后用Fraction精确计算δ=‖VᵀV−I‖∞和残差R=AV−VΛ。令r=max(‖R‖₁,‖R‖∞)、M=‖A‖∞、L=max|Λ|，要求δ<1/2。用V的正交极分解因子Q可得：‖A−VΛVᵀ‖₂≤2r+Mδ，‖VΛVᵀ−QΛQᵀ‖₂≤3Lδ。再加d倍最大矩阵项转换误差，得到排序特征值的包围。这里使用标准极分解与扰动估计，不声称新数学结果或已形式化验证实现。
