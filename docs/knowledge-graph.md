# 知识图谱工作规范

用户强调知识图谱整理是重要工作。图谱作为持续研究的主交付物：每次原文阅读、历史纠错、接口审计、实验和应用判断，都回写可追踪关系；报告及可视化由规范记录生成。

规范事实源是 `data/corpus/` 与 `data/graph/`，不是导出的HTML。保留稳定ID、精确来源位置／版本／散列；改事实先存旧版本与修改理由。原始主张、实际选读、形式规格、完整证明链、实验观察和真实人审分别记录。

| 组织层 | 应能回答的问题 | 必须保留的内容 |
| --- | --- | --- |
| 成果族／版本／结论 | 哪一稿、哪项结果？是否撤回或替代？ | 手稿版本与合格具名结果绑定；全文草稿和完整研究分别计数 |
| 历史／证据 | 根据什么知道？实际核对了哪些范围？ | 原始版本、局部阅读范围、内容核验状态；仅书目登记不能变成全文已读 |
| 方法／条件 | 输入、输出、量词、成本和失效条件是什么？ | 定理条件和应用额外假设；存在性、构造性、可运行与实用收益分开 |
| 旧方法／对比 | 旧方法是否已经足够？ | 最强合格基线和完整成本；已知控制例不计新增数学增益 |
| 应用／检验／缺口 | 语义桥是否成立？还缺哪项证据？ | 真实问题、条件候选、冻结协议、实际run与重启条件；缺口不能被相关边掩盖 |

`depends_on／uses／derived_from` 仅在存在相应依赖时使用，方向从使用者到所需证据或先决条件；它们会进入影响传播。条件未建立时明确标记，不因此给主定理定为错误。`compared_with` 表示旧基线；`has_scope_condition／scope_mismatch` 表示真实接口的限制与迁移差异；`reviews` 表示实际审计对象。历史背景、类比和范围不匹配不能伪装成已验证的正向依赖。

从 [离线图谱](../reports/graph/index.html) 搜索族、结论、方法或APP节点，沿邻域查看来源与限制；[全局导航索引](../reports/graph/navigation.md)列出所有登记族、候选、显式基线和待补条件。命令行入口不需要安装依赖：

```sh
PYTHONPATH=src python3 -m ai_value.cli query APP-243-01
PYTHONPATH=src python3 -m ai_value.cli query CHECK-243-QUERY-CONTRACTS
PYTHONPATH=src python3 -m ai_value.cli export-graph
PYTHONPATH=src python3 -m ai_value.cli organize-graph
python3 scripts/check.py
```

F243本轮是完整示例：候选连接实际主机、强旧消元、尚缺编译证据与紧凑编码，保留而降低实现优先级。详见[接口与条件审计](../reports/F243-query-interface-audit.md)。没有把两项接口审阅增加为两条候选或初检。

整理顺序是先查身份／版本与错误合并，再查来源与依赖，再查适用条件和旧方法，最后补跨族可迁移路径。每包运行完整来源、外键、状态闸门及导出检查；每三包全局复盘抽查影响传播和实质不同路线。只统计实际完成内容，不以总节点数、重复别名或探索次数充当覆盖率。WP059已从规范记录生成结构缺口索引；[实际整理报告](../reports/knowledge-graph-organization.md)区分显式关系、文本提示和仍需语义审核的内容，索引存在不等于缺口已经补齐。

数值输出与代码快照压缩保存，回解散列核验后清理临时明文；不复制3.1GB上游或下载大型运行环境。真实人审和第二供应商待后补，保持缺口但继续独立工作。当前仅本地保存／提交，发布与推送另行记录。

F142增加另一项实际整理示例：[矩阵接口核查](../reports/F142-matrix-interface-audit.md)连接真实模块直和分解、旧同态／Fitting方法和候选输出语义、同等结构基线两项未建立闸门。范围不匹配边不进入主定理失效传播；不能把该接口审计计为已执行应用检验。

F094增加实际数据对象与待补语义／有限构造的示例：[就绪核查](../reports/F094-bold-readiness-audit.md)。数据可取得、可读数值、语义合格、算法可执行与应用成功分别记录。数据只作为相关候选资源；应用额外前提不反向污染数学结论，强旧基线关系不冒充证明依赖。
