# 数据与统计口径

`data/corpus/baseline.json` 固定来源、commit、口径及处理版本。`files.jsonl.gz` 为所有上游受控文件的 path/bytes/SHA-256；`manuscripts.jsonl` 的 ID 由固定路径散列产生，版本变更必须新节点；`families.jsonl` 使用原编号，不填补不存在的 045/061/070/123/163。

`reconciliation.jsonl` 每条旧目录手稿恰有一项对应：原路径不变、README 明确 previous-version 链接的修订、或有具体撤回公告的证明撤回。路径不变不代表已比较两个 commit 的全部文件内容。固定版本证据以当前全量散列为准。

研究节点要求稳定 ID、版本、实际时间、证据状态、定位来源、属性。节点种类：命题、方法/构造、历史文献、应用问题、候选连接、探索尝试、生成记录、审核、撤回。完整模式与语义约束分别见 `schemas/graph-node.schema.json` 和 `src/ai_value/graph.py`。

加载后的知识图谱还含从规范外键投影的学科、成果族、手稿、语料版本及来源文件节点。`member_of` 是目录归属；`historical_context` 不等于已证明依赖；`cites` 是引用定位；`depends_on/uses/derived_from` 才参与理论依赖等级传播。来源变化沿引用及依赖关系传给卡片，数学 D 级沿实际依赖传播；历史背景引用不能自动变成证明依赖。

数学评级、应用结果、流程状态是三条轴。A 要有真实规格审核；B 是明确对应命题的上游形式化声明，另记本地构建/Comparator；未逐条核对范围的登记记录为 unknown。部分形式化不覆盖全族。卡片依赖闭包不完整时保持 unknown；局部 B 不自动升级整卡。

候选连接以具体零件、问题和独立可证伪预测去重。一次跨域尝试未形成有条件的具体连接，不计入候选。不同种子、重复运行、压缩迁移与复现均不增加独立假设数。

初检卡片需字段完整且已有实际外部检验输出，数值适用性筛查必须单列，不能伪装成新算法基准。通过数量与初检数量分开；待审不利结果为观察，正式否定需两个真实审稿人。人工分级只数真实外部审核凭据，模型角色评分不数。

入库覆盖率、完整拆解覆盖率、六阶段覆盖率分开。当前分别为 372/372、0/372、0/372；局部阅读单列。人审错误率尚无样本，值为 null，不是 0%。每周 5% 抽样按候选总体取上整，随机种子及当周待审状态保存。

清洁检出无 `math/` 时，来源散列校验对照固定压缩清单，明确不属于重新读取原文；有本地源文件时直接重算内容散列。外部 URL 打开与内容支持核对分别记录，网络失败保持缺口。

`family_analysis` 保存全文拆解草稿、具名结果、方法、常数、自然语言与形式化静态对照。`source_decomposition_draft_complete` 只说明正文具名结果有逐项草稿，不表示全族历史谱系、证明、人审或六阶段完成。多手稿必须使用 `result_ids_by_source`（路径→原标签→节点），展示键带手稿前缀，防止重复的 `thm:main` 合并。每个本地 BibTeX 键也有手稿作用域；不同论文即使同键也不能合并，同一 DOI 可以共用文献节点。

静态 Lean 导入索引压缩保存，词法未见 sorry/axiom 不等于构建或 Comparator 检查通过；编号命名空间也不能作为成果族归属依据。零件检查用 `component_run_ids` 单列；不增加连接、完整初检卡片或不同应用假设数。运行超出资源预算时仍压缩保存已有数据和快照，结果标记 `resource_envelope_exceeded`；资源检查是事后记录，不是操作系统强制限额。

多手稿成果族可以记录 `manuscript_source_drafts_complete_ids`，只计入实际读完的手稿。部分手稿不会使 `source_decomposition_draft_complete` 为真；校验器检查源模块归属、手稿覆盖和每个文件的具名结果，导出标题明确标为局部拆解。
