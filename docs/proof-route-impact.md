# 证明路线与前提变化影响预览

知识图谱可以查询某些前提发生变化后需要复核的范围。它区分普通必需依赖和显式登记的替代证明路线；结果不是定理真假的自动判断。

打开 `reports/graph/index.html`，搜索并选择节点，在“前提变化影响预览”填写一个或多个节点ID，或点“加入当前节点”，再点“预览影响”。空格、换行及逗号均可分隔ID。预览只读取图谱，不修改任何证据、可信度或验收状态。

当前F210有两条明确路线：

- `PART-210-SHORT-ROUTE`：伴随稿二次阈值＋有限小次数检查。
- `PART-210-INDEPENDENT-ROUTE`：独立图表界＋完整有限范围检查。

| 模拟需复核的前提 | 传播结果 |
| --- | --- |
| `CLM-210-Q-THM-MAIN` | 二次路线受影响，独立路线未被此输入影响；不联动主结论 |
| `CLM-210-M-PROP-LARGE` | 独立路线受影响，二次路线未被此输入影响；不联动主结论 |
| 上面两项同时输入 | 两条登记路线均受影响，主结论及下游零件需复核 |
| `CLM-210-M-VER-BAND` | 当前粗粒度记录中为两路线共享的有限证据，两条均需复核 |
| `CLM-210-M-THM-MAIN` 本身 | 直接指定主结论需复核，继续传播到下游；不要求先影响路线 |

命令行可取得完整ID列表（页面最多显示前100项）：

```sh
PYTHONPATH=src python3 -m ai_value.cli impact CLM-210-Q-THM-MAIN
PYTHONPATH=src python3 -m ai_value.cli impact CLM-210-Q-THM-MAIN \
  --changed CLM-210-M-PROP-LARGE
```

也可重复使用`--changed`而不传位置ID。未知ID或空输入会明确报错。

普通`depends_on`、`uses`、`derived_from`、`cites`仍按必需依赖传播。声明为`alternative_proof_route_ids`的非空方法ID列表表示一个显式OR组：全部登记路线受影响后才联动所属claim。普通必需依赖与这个OR组并存；`supports`、历史背景、比较关系本身不触发必需依赖传播。

实现从输入计算最小固定点，循环不会自行启动。声明必须属于claim，路线必须是存在、唯一的方法节点且不能引用自己。程序只校验这些结构条件，不证明路线正确、独立或完整；未受影响不等于已验证。当前不自动发现路线，也不推导任意布尔组合或参数分段。共享计算记录的细分范围若变化，仍需人工读具体证据。

WP071／GEN067的源文台账和当时“尚无OR传播”的回执保持原样；WP073／GEN069以精确旧版本归档更新当前主声明注释。F210主结论仍为C，完整族／历史、人审与独立供应商验收没有被提升。

实现和验证证据位于`reports/reproducibility/20261021-proof-routes/`：55项核心测试、九组真实图谱浏览器逻辑与Python结果对照、CLI、实际页面操作与截图、源引用／版本、压缩导出、干净目录及归档检查分别留证。软件测试不增加应用初检或不同数值假设。
