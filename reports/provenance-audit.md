# 图谱来源与版本保留审计

日期：2026-10-21，WP-031。规范研究事实、卡片结果和原实验输出未改；修复来源投影与字段契约。

当前 1,942 条规范引用逐条对应来源注释，定位、时间、版本与散列字段完整回查，每条引用恰有一条投影边。514 个来源节点中，249 个汇集多条引用；这些数量均不是论文或证明审核数量。

- 已知字节散列的同一来源汇集全部注释，保留既有来源 ID；同一节点对同一文件引用多处时只生成一条边，同时保留每个引用下标与定位。
- 外部 URL 有内容散列或明确版本时分别记录；没有这些依据时保留完整观察记录，不以 URL 相同推断同一版本。114 个未定字节身份的外部观察仍保留原本实际核对的范围，不把局部 `content_checked` 升为整个来源通过。
- 旧实现中两处 URL 对应不同注释，来源节点只显示最后一条，分别为 arXiv `2103.05934v2` 和 Beckermann 作者 PDF。规范引用与边定位本来仍在，现修复来源节点展示；没有据此判定原文数学结论错误。
- schema 1.1 明确三种既有可选元数据：更新时间、更新批次、前版归档。节点字段契约现在拒绝未知字段、无时区时间与非正整数版本；归档检查覆盖单条与既有 `records`/`nodes` 批量格式，并核对身份、先后版本、目录范围和更新批次外键。这是本项目的契约校验，不是通用 JSON Schema 引擎。
- DOI/arXiv 工作标识只产生待审路由，绝不自动合并论文、版本或证据。388 个文献节点中 141 个有显式 DOI 字段；本轮严格标识规则没有形成重复组。其余条目可能有 arXiv 链接，也可能缺少可比标识，不能由零组推断全库没有重复或历史谱系已完成。

新增五项回归覆盖注释覆盖丢失、外部版本混并、同文件多定位重复边、身份候选误合并，以及严格字段/前版格式。42 项核心测试通过；实际全量注释回查现已纳入 `scripts/check.py`。压缩图、干净目录、归档与重放证据见 `reports/reproducibility/20261021-provenance/`。仅图谱表示增加两个来源节点，总数 2,910；关系 7,090，研究节点仍 1,245，候选 18/初检 10/限定支持 5 均不变。

可执行入口：`python3 scripts/audit_graph_provenance.py`。压缩明细：`reports/graph/provenance-audit.json.gz`。完整历史、形式依赖、人审和独立模型审核仍未完成。
